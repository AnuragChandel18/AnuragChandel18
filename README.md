### 📄 PDF RAG Chatbot

Upload a PDF and ask questions about it. The app searches the document for relevant passages and uses the Google Gemini API to answer from them.

### 🗄️ PostgreSQL Data Warehouse

A data warehouse built from CRM and ERP sales data, organized into Bronze, Silver, and Gold layers. Started from a course project written for SQL Server and rebuilt in PostgreSQL.

- Medallion architecture: Bronze (raw), Silver (cleaned), Gold (analysis-ready)
- Star schema with `dim_customers`, `dim_products`, and `fact_sales`
- Six source files (3 CRM, 3 ERP) loaded and transformed through SQL
- Uses window functions (`ROW_NUMBER`, `LEAD`) and CTEs

**Stack:** PostgreSQL · SQL · Medallion Architecture · Star Schema

[![Source Code](https://img.shields.io/badge/Source_Code-GitHub-181717?style=for-the-badge&logo=github&logoColor=white)](https://github.com/AnuragChandel18/SQL-Data-Warehouse-Project)
